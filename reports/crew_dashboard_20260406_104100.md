# Engineering Brief: Fleet-Wide Anomaly Report

## 1. Executive Summary

A systemic, fleet-wide anomaly has been detected across all six monitored bridges, placing the entire fleet under a high-risk advisory. The `stacked_spatiotemporal_bridge_ensemble_v2` model detected this event with high confidence (max_probability: 1.0), driven primarily by a significant spike in the 'Probability_of_Failure_PoF_roll_std_12' feature. The Pacific Crown Bridge has been identified as a critical-risk asset, requiring immediate on-site inspection due to its high anomaly count (129) and a peak sensor-based probability of failure of 0.71. All other bridges are on a watchlist for heightened monitoring.

## 3. Visual Highlights

The admin dashboard should reflect the urgency of this event with the following visual cues:
- **Hero Message:** The main dashboard title should read "Fleet-Wide Anomaly Detected" with a message emphasizing the critical risk to the Pacific Crown Bridge.
- **Fleet Status:** The fleet status indicator should be set to 'CRITICAL' in bright red.
- **Geo-Map:** The Pacific Crown Bridge should be marked with a pulsing red, high-priority icon. All other bridges should have static amber 'caution' icons.
- **Chart Annotations:** Time-series charts should highlight the spike in the 'Probability_of_Failure_PoF_roll_std_12' feature. The detail view for Pacific Crown should pinpoint the 129 anomaly events and the peak 0.71 probability of failure.
